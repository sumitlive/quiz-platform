🚀 QUICK START (3 COMMANDS)
═══════════════════════════════════════════════════════════════════════════════

WINDOWS:
  1. cd quiz-platform
  2. start-windows.bat
  3. Browser opens at http://localhost:3000

MAC/LINUX:
  1. cd quiz-platform
  2. chmod +x start.sh && ./start.sh
  3. Browser opens at http://localhost:3000

Manual (both):
  Terminal 1: cd server && npm install && npm start
  Terminal 2: cd client && npm install && npm start

❌ TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Port already in use?
  → See RUN_INSTRUCTIONS.txt "Common Issues" section

npm command not found?
  → Install Node.js from https://nodejs.org/

Can't connect frontend to backend?
  → Make sure both servers are running
  → Check http://localhost:3001/health in browser

Missing dependencies?
  → Delete node_modules folder
  → Run: npm install again

💡 KEY FEATURES
═══════════════════════════════════════════════════════════════════════════════

Quiz Mode:
  • Random question from database
  • Markdown-formatted with code syntax highlighting
  • Countdown timer with visual progress ring
  • Reveal answer button
  • Auto-reveal on timer expire
  • Next question for another problem
  • Filter by topic (Python, C++, SQL)
  • Filter by difficulty (Easy, Medium, Hard)
  • Streak counter

Admin Mode (Click ⚙️):
  • Create new questions
  • Edit existing questions
  • Delete questions
  • Search questions
  • Markdown editor with live preview


🔌 API ENDPOINTS
═══════════════════════════════════════════════════════════════════════════════

GET  /questions/random           Random question
GET  /questions                  All questions
GET  /questions/:id              Single question
POST /questions                  Create question
PUT  /questions/:id              Update question
DELETE /questions/:id            Delete question
GET  /topics                     List topics
GET  /health                     Health check
