🚀 HOW TO RUN
═══════════════════════════════════════════════════════════════════════════════

QUICKEST WAY (Recommended):

Windows:
  1. Open Command Prompt in quiz-platform folder
  2. Run: start-windows.bat
  3. Two windows open with both servers
  4. Go to: http://localhost:3000

Mac/Linux:
  1. Open Terminal in quiz-platform folder
  2. Run: chmod +x start.sh && ./start.sh
  3. Wait for "Both servers are running" message
  4. Go to: http://localhost:3000


MANUAL METHOD (If scripts fail):

Terminal 1:
  $ cd quiz-platform/server
  $ npm install
  $ npm start
  
  Expected: 🚀 Quiz Platform API running at http://localhost:3001

Terminal 2:
  $ cd quiz-platform/client
  $ npm install
  $ npm start
  
  Expected: Browser opens to http://localhost:3000

STOP SERVERS:
  Press CTRL+C in each terminal

🔧 API ENDPOINTS (For Advanced Use)
═══════════════════════════════════════════════════════════════════════════════

Basic Requests:

GET /questions/random
  Returns: Random question object
  Example: http://localhost:3001/questions/random

GET /questions
  Returns: Array of all questions
  Example: http://localhost:3001/questions

With Filters:

GET /questions/random?topic=Python&difficulty=easy
  Returns: Random easy Python question

GET /questions?search=array&difficulty=medium
  Returns: All medium difficulty questions mentioning "array"

GET /topics
  Returns: ["C++", "Python", "SQL"]

CRUD Operations:

POST /questions (Create)
  Body: {topic, question, answer, difficulty, timer_seconds}

PUT /questions/5 (Update)
  Body: {field: new_value}

DELETE /questions/5 (Delete)
  Returns: {message: "Question deleted", id: 5}

GET /health (Health Check)
  Returns: {status: "ok", timestamp: "..."}
