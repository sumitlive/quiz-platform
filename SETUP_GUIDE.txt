💡 COMMON ISSUES & FIXES
═══════════════════════════════════════════════════════════════════════════════

ISSUE: "Port 3000 already in use"
┌─────────────────────────────────────────────────────────────────────────┐
│ SOLUTION:                                                               │
│   Windows: netstat -ano | findstr :3000                               │
│            taskkill /PID <PID> /F                                      │
│                                                                         │
│   Mac/Linux: lsof -i :3000                                            │
│             kill -9 <PID>                                             │
│                                                                         │
│ OR: Change port in client/src/api.js line 1                          │
└─────────────────────────────────────────────────────────────────────────┘

ISSUE: "Port 3001 already in use"
┌─────────────────────────────────────────────────────────────────────────┐
│ SOLUTION:                                                               │
│   Windows: netstat -ano | findstr :3001                               │
│            taskkill /PID <PID> /F                                      │
│                                                                         │
│   Mac/Linux: lsof -i :3001                                            │
│             kill -9 <PID>                                             │
│                                                                         │
│ OR: Start backend on different port:                                   │
│     PORT=3002 npm start                                               │
└─────────────────────────────────────────────────────────────────────────┘

ISSUE: "npm command not found" or "npm: command not found"
┌─────────────────────────────────────────────────────────────────────────┐
│ SOLUTION: Node.js is not installed or not in PATH                      │
│   1. Download Node.js: https://nodejs.org/                            │
│   2. Install it (choose LTS version)                                  │
│   3. Restart your terminal                                            │
│   4. Verify: type "node --version"                                    │
└─────────────────────────────────────────────────────────────────────────┘

ISSUE: "Cannot find module" errors
┌─────────────────────────────────────────────────────────────────────────┐
│ SOLUTION: Dependencies not installed                                    │
│   1. In server folder: rm -rf node_modules && npm install            │
│   2. In client folder: rm -rf node_modules && npm install            │
│   3. Try again                                                         │
└─────────────────────────────────────────────────────────────────────────┘

ISSUE: Database errors or questions missing
┌─────────────────────────────────────────────────────────────────────────┐
│ SOLUTION: Reinitialize database                                        │
│   1. Delete: server/quiz.db                                           │
│   2. Restart backend server                                           │
│   3. Database will auto-create with sample data                       │
└─────────────────────────────────────────────────────────────────────────┘

ISSUE: Frontend not connecting to backend (CORS errors)
┌─────────────────────────────────────────────────────────────────────────┐
│ SOLUTION:                                                               │
│   1. Verify backend is running (check terminal)                       │
│   2. Check http://localhost:3001/health in browser                   │
│   3. Both must be running on correct ports                           │
│   4. Check network in browser dev tools (F12)                        │
└─────────────────────────────────────────────────────────────────────────┘

🔧 CREATING A QUESTION (Example)
═══════════════════════════════════════════════════════════════════════════════

TOPIC:       Python
DIFFICULTY:  medium
TIMER:       90 seconds

QUESTION (Markdown):
┌─────────────────────────────────────────────────────────────────────────┐
│ ## Reverse a List                                                       │
│                                                                         │
│ Write a function to reverse a Python list **in-place**.                │
│                                                                         │
│ **Example:**                                                            │
│                                                                         │
│ ```python                                                               │
│ lst = [1, 2, 3, 4, 5]                                                 │
│ reverse_list(lst)                                                      │
│ print(lst)  # [5, 4, 3, 2, 1]                                         │
│ ```                                                                     │
│                                                                         │
│ **Constraints:**                                                        │
│ - O(1) extra space                                                     │
│ - Don't create a new list                                             │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘

ANSWER (Markdown):
┌─────────────────────────────────────────────────────────────────────────┐
│ ## Solution                                                             │
│                                                                         │
│ Use two pointers (left and right) and swap elements:                  │
│                                                                         │
│ ```python                                                               │
│ def reverse_list(lst):                                                │
│     left, right = 0, len(lst) - 1                                    │
│     while left < right:                                               │
│         lst[left], lst[right] = lst[right], lst[left]                │
│         left += 1                                                      │
│         right -= 1                                                     │
│                                                                         │
│ # Test                                                                 │
│ lst = [1, 2, 3, 4, 5]                                                │
│ reverse_list(lst)                                                     │
│ print(lst)  # [5, 4, 3, 2, 1]                                        │
│ ```                                                                     │
│                                                                         │
│ **Time Complexity:** O(n)                                             │
│ **Space Complexity:** O(1)                                            │
│                                                                         │
└─────────────────────────────────────────────────────────────────────────┘

Then click [Create] and it appears in the questions list!

🌐 API ENDPOINTS (For Advanced Use)
═══════════════════════════════════════════════════════════════════════════════

GET  /questions/random           → Random question
GET  /questions/random?topic=Python&difficulty=hard
GET  /questions                  → All questions
POST /questions                  → Create question
PUT  /questions/:id              → Update question
DELETE /questions/:id            → Delete question
GET  /topics                     → List all topics
GET  /health                     → Health check

Example using curl:
  curl http://localhost:3001/questions/random
  curl http://localhost:3001/topics
  curl -X POST http://localhost:3001/questions \
    -H "Content-Type: application/json" \
    -d '{"topic":"JavaScript","question":"...","answer":"...","difficulty":"easy","timer_seconds":60}'
