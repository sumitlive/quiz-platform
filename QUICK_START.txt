⚡ FASTEST WAY TO GET RUNNING (3 MINUTES)
═══════════════════════════════════════════════════════════════════════════════

On WINDOWS:
───────────
1. Open Command Prompt in the quiz-platform folder
2. Type:  start-windows.bat
3. Wait 30 seconds, two windows will open
4. Your app is at: http://localhost:3000

On MAC or LINUX:
────────────────
1. Open Terminal in the quiz-platform folder
2. Type:  chmod +x start.sh && ./start.sh
3. Wait 30 seconds for "Both servers are running" message
4. Your app is at: http://localhost:3000

❌ TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

PROBLEM: "Port 3000 already in use"
SOLUTION: 
  • Close other applications using port 3000
  • Or change the frontend port:
    Windows: set PORT=3002 && npm start
    Mac/Linux: PORT=3002 npm start

PROBLEM: "Port 3001 already in use"
SOLUTION:
  • Close other applications using port 3001
  • Or change backend port:
    Windows: set PORT=3002 && node index.js
    Mac/Linux: PORT=3002 node index.js

PROBLEM: "npm: command not found"
SOLUTION:
  • Install Node.js: https://nodejs.org/
  • Make sure to add to PATH during installation
  • Restart terminal/command prompt
  • Verify: node --version (should show v14+)

PROBLEM: Database errors or missing questions
SOLUTION:
  • Delete: server/quiz.db
  • Restart backend server
  • Database will auto-recreate with sample data

PROBLEM: Frontend can't connect to backend (CORS errors)
SOLUTION:
  • Make sure both servers are running
  • Check http://localhost:3001/health in browser
  • Backend must be on 3001, frontend on 3000

PROBLEM: "npm install" takes too long or fails
SOLUTION:
  • Try clearing npm cache: npm cache clean --force
  • Delete node_modules folder and package-lock.json
  • Run npm install again
  • Check your internet connection

🎓 EXAMPLE: CREATE YOUR FIRST QUESTION
═══════════════════════════════════════════════════════════════════════════════

1. Click the ⚙️ gear icon in bottom right
2. Click "New Question" button
3. Fill in:

   Topic: JavaScript
   
   Difficulty: easy
   
   Timer: 45
   
   Question (click WRITE tab):
   ────────────────────────────
   ## Reverse an Array
   
   Write a function to reverse an array in-place.
   
   ```javascript
   const arr = [1, 2, 3, 4, 5];
   reverseArray(arr);
   console.log(arr); // [5, 4, 3, 2, 1]
   ```

   Answer (click WRITE tab):
   ────────────────────────
   ## Solution
   
   Use two pointers (left and right) and swap:
   
   ```javascript
   function reverseArray(arr) {
     let left = 0, right = arr.length - 1;
     while (left < right) {
       [arr[left], arr[right]] = [arr[right], arr[left]];
       left++;
       right--;
     }
   }
   ```
   
   **Complexity:** O(n) time, O(1) space

4. Click [Create]
5. Your question now appears in the quiz! 🎉
