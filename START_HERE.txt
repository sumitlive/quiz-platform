🚀 HOW TO RUN (CHOOSE ONE METHOD)
═══════════════════════════════════════════════════════════════════════════════

⚡ FASTEST WAY (Recommended - Automated):
─────────────────────────────────────────

WINDOWS:
  1. Open Command Prompt in quiz-platform folder
  2. Type:  start-windows.bat
  3. Wait ~30 seconds
  4. Two new windows open with servers
  5. Browser opens to http://localhost:3000
  6. Done! 🎉

MAC / LINUX:
  1. Open Terminal in quiz-platform folder
  2. Type:  chmod +x start.sh
  3. Type:  ./start.sh
  4. Wait for "Both servers are running" message
  5. Go to http://localhost:3000
  6. Done! 🎉


📖 STEP-BY-STEP MANUAL METHOD:
────────────────────────────────

TERMINAL 1 - Backend:
  $ cd quiz-platform/server
  $ npm install
  $ npm start
  
  Wait for: 🚀 Quiz Platform API running at http://localhost:3001

TERMINAL 2 - Frontend:
  $ cd quiz-platform/client
  $ npm install
  $ npm start
  
  Wait for: Compiled successfully!
  
Browser will open to: http://localhost:3000

🎯 EXAMPLE: CREATE YOUR FIRST QUESTION
═══════════════════════════════════════════════════════════════════════════════

1. Click gear icon (⚙️) in bottom-right
2. Click "New Question"
3. Fill in:

   Topic:        JavaScript
   Difficulty:   medium
   Timer:        60
   
   Question:
   ─────────
   ## Fibonacci Sequence
   
   Write a function to return the Nth Fibonacci number.
   
   ```javascript
   fibonacci(5)  // returns 5
   fibonacci(6)  // returns 8
   ```
   
   Answer:
   ──────
   ## Solution
   
   ```javascript
   function fibonacci(n) {
     if (n <= 1) return n;
     return fibonacci(n - 1) + fibonacci(n - 2);
   }
   ```
   
   **Complexity:** O(2^n) time, O(n) space

4. Click [Create]
5. Question appears in quiz immediately!
